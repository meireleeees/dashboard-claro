# 📊 Dashboard de Desempenho por Regionais

Este projeto é um dashboard interativo desenvolvido para análise de desempenho de regionais em um programa de excelência.

## 🚀 Funcionalidades

- Cálculo de nota final com penalização
- Classificação automática (Black, Platinum, etc.)
- Simulação de remuneração por desempenho
- Filtros por ciclo e regional
- Comparação entre regras antiga e nova
- Gráficos interativos e insights automáticos

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript
- Chart.js

## 🎯 Objetivo

Simular um cenário real de negócio para análise de performance e tomada de decisão baseada em dados.

## ▶️ Como executar

1. Baixe o projeto
2. Abra o arquivo `index.html` no navegador
